<h3>[ 01 ] &nbsp;SOBRE MÍ</h3>

Developer en **[Aracari Studios](https://github.com/Aracari-Studios)**. Trabajo desde El Salvador en backend, ingeniería de datos y la infraestructura que los mantiene vivos.

Ahora mismo estoy construyendo el ecosistema **YHAT**: un SDK de ETL, un servidor MCP y una plataforma de conocimiento con agentes que capturan lo que el equipo sabe. En mis ratos libres escribo un CRM en Rust para pelearme con el borrow checker.

```text
main          → protegida. siempre.
flujo         → feat/* → PR → review → CI verde → merge
push --force  → no.
infra         → todo en Docker, todo monitoreado
```
